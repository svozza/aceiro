# Smtithy experiment results

This repository owns smtithy's redacted native experiment records as well as
the canonical cross-arm result schema. Comparative conclusions remain in the
central report, not in individual arm records.

Records under `results/experiments/` validate against
`src/smtithy/evals/arm_result.schema.json`. Large transcripts remain external
redacted artifacts referenced by run ID and SHA-256. See ADR 0020 before
adding, moving, or interpreting results.
