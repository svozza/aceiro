# Four CLEF follow-ups

The user approved independent component questions, allegation-blind behavior checks, fresh repositories and a CLEF-Flash comparison on the already provisioned Spot H100. Keep source as data and leave cloud teardown to the user.

Independent questions test the observed mismatch between correctly rejected component claims and wrongly accepted whole claims. Controlled neutral questions isolate allegation effects. Twenty-four prelabelled source cases from eight repositories absent from the pilot test transfer beyond those reused cases. Flash measures the capacity/latency tradeoff using the same fixed inputs and GPU.

All arms are frozen before inference, with labels local only, strict token preflight and no semantic reruns or tuning. Existing CLEF pilot results are reused as the baseline; its archive is unchanged. Detailed counts and success criteria are in handoff/clef-followups-20261008/PROTOCOL.md. No production integration or automated component-voting rule is included.
