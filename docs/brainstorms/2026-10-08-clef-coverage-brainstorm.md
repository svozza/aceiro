# Coverage before fact inference

The user approved testing independent evidence coverage before asking CLEF factual questions. Use trusted byte parsing to derive the complete code-token locations for explicitly declared symbols/blocks, then check what source the model will actually receive. This reduces dependence on the model's unreliable confidence about missing implementation.

Requirements remain explicit rather than automatically inferred. Test complete inputs, old and novel gaps, harmless omissions, source versions, external-population prerequisites and a hard semantic over-deferral. A HEAD-only fact may remain answerable when BASE is missing. Compare gated and ungated policy on one matched set of52 model responses, avoiding duplicate inference.

Do not confuse syntax coverage with complete semantic dependencies or bug truth. Preserve existing source-only isolation and all prior evidence, and leave the Spot host running until the user decides teardown. Detailed controls are in handoff/clef-coverage-20261008/PROTOCOL.md.
