# Smaller native clause controller

User approved the next revision after construction completed only 1/8 pipelines.
The active CLI now uses one assessment session per mode. Constructor/manual
parser-ID schema and registry dump are removed. The controller binds ordinary
exact source citations to operations and checks owners; parser remains unchanged.

The new BASE states represent direct blocking separately from downstream
not-reached/different observations with causal references. Evidence questions
have necessary/optional and resolved/unresolved state, so real supported cores
are not vetoed by resolved questions or unknown auxiliary claims. Every original
sentence gets a verdict and exact supported optional text is assembled without
another model writer. The same session composes/judges the core; this is not an
independent semantic proof, and false supported statements can still survive.

Sixteen fresh cases compare clause assessment with unchanged monolithic prompt/
schema, sharing the source/catalog-only packet, same model/high effort and total
180-second allowance. No historical controls or extra cases. Positive joint
success must preserve actual new path while removing bad permanence; old-race
negative must be correctly classified and withheld. Full proposed text, sources,
binding/obligation decisions, failures and costs are audited. No rollout follows.
